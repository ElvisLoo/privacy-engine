# 防窥助手 · Privacy Engine

给本机屏幕叠一层「中间透、四周暗」的遮罩，降低旁边人扫一眼能读到的信息量。

**它不是什么**：不检测有没有人在看，不调用摄像头，不上传任何数据，也不能替代物理防窥膜。
它的原理就是一层半透明窗口 —— 说清楚这一点，比夸大效果重要。

## 能做什么

- **全屏圆形**：以鼠标位置为中心开一个清晰圆孔，其余区域变暗
- **左右三区域**：中间留一条清晰的竖直带，两侧变暗
- 强度可调（0–100%）
- 全局热键：`F6` 切换圆形 / `F7` 切换三区域 / `F8` 减弱 / `F9` 增强

## 安装与启动

1. 安装 Python 3.9+（安装时勾选 **Add Python to PATH**）
2. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

3. 启动：

   ```bash
   python privacy_engine.py
   ```

   > 全局热键需要管理员权限，否则 `F6`–`F9` 不生效（界面会提示）。
   > 只用界面按钮的话不需要提权。

Windows 下也可以右键「以管理员身份运行」。

## 隐私说明

- 不上传任何数据；唯一的网络访问是点击界面上的 JIKEGANG 按钮打开官网
- 不调用摄像头，不抓取屏幕内容，不写日志文件
- 遮罩只是画在你自己屏幕上的半透明窗口，对他人不可见

## 常见问题

**按 F6 没反应**
多半是没用管理员权限运行。界面顶部会显示「全局热键不可用」，换用左侧按钮即可。

**关闭窗口后屏幕还是暗的**
这是旧版本的缺陷（遮罩窗口没有随主窗口销毁）。当前版本已修复；如果你还遇到，
请确认用的是最新代码。

**Linux / macOS 能用吗**
界面能跑，但 `keyboard` 库在 Linux 需要 root、macOS 需要辅助功能授权，
且部分桌面环境的合成器会让遮罩挡住鼠标。目前主要面向 Windows。
